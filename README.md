# 📊 Curso PowerBI_Ago2026 - Preparación Certificación PL-300

Bienvenido al repositorio oficial del curso **PowerBI_Ago2026**. Este espacio está dedicado a documentar el progreso, scripts y modelos de datos creados como parte del entrenamiento continuo y la preparación para la certificación **Microsoft PL-300 (Power BI Data Analyst)**.

## 🎯 Objetivo del Repositorio
Consolidar los conocimientos técnicos en análisis de datos, con un enfoque particular en la preparación de datos desde el backend utilizando **SQL Server 2022** y **TRANSACT/SQL (T-SQL)** para alimentar modelos semánticos eficientes en Power BI. El objetivo final es construir soluciones analíticas orientadas a los negocios.

## 🛠️ Tecnologías y Herramientas
* **Motor de Base de Datos:** SQL Server 2022
* **Procesamiento ETL:** TRANSACT/SQL (T-SQL)
* **Modelado y Visualización:** Power BI Desktop
* **Lenguajes Analíticos:** DAX, M (Power Query)
* **Diagramado Arquitectónico:** draw.io / Mermaid

## 📂 Estructura del Curso y Guía de Estudio (Temario de 20 Días)

El programa está dividido en cuatro fases principales, cubriendo desde la extracción en bases de datos hasta la distribución de reportes analíticos con inteligencia de negocios.

### Fase 1: Preparación de Datos (Backend y Power Query)
* **Día 1: Fundamentos y Entorno.** Configuración de orígenes de datos, conexión a SQL Server y navegación básica en Power BI Desktop.
* **Día 2: Transformación de Datos y Modelado Dimensional.** Construcción de esquemas estrella (Star Schema) desde T-SQL, limpieza de estructuras y llaves compuestas.
* **Día 3: Limpieza y perfilado en Power Query (Lenguaje M).** Identificación de anomalías, manejo de errores y transformaciones de texto/fecha.
* **Día 4: Modos de Almacenamiento.** Diferencias, ventajas y casos de uso entre Import, DirectQuery y Dual.
* **Día 5: Optimización de Consultas.** Uso de parámetros, plantillas y Query Folding para delegar la carga al motor de base de datos.

### Fase 2: Modelado de Datos (DAX y Relaciones)
* **Día 6: Diseño de Relaciones.** Configuración de cardinalidad (1:*, 1:1) y dirección del filtro cruzado (único y bidireccional).
* **Día 7: Introducción a DAX.** Diferencias fundamentales entre columnas calculadas, tablas calculadas y medidas.
* **Día 8: Inteligencia de Tiempo (Time Intelligence).** Creación de métricas acumuladas y comparativas (YTD, MTD, SAMEPERIODLASTYEAR).
* **Día 9: Funciones DAX de Filtro e Iteración.** Dominio del contexto de evaluación con `CALCULATE`, `FILTER` y funciones iteradoras como `SUMX`.
* **Día 10: Seguridad a Nivel de Fila (RLS).** Implementación de roles de seguridad estáticos y dinámicos basados en jerarquías corporativas.
* **Día 11: Rendimiento del Modelo.** Análisis de métricas de VertiPaq Analyzer y reducción del tamaño del modelo.

### Fase 3: Visualización y Análisis (Reporting)
* **Día 12: Diseño de Reportes e Interactividad.** Mejores prácticas visuales, sincronización de segmentadores (Slicers) y edición de interacciones.
* **Día 13: Experiencia de Usuario (UX).** Implementación de marcadores (Bookmarks), botones y navegación fluida entre páginas.
* **Día 14: Exploración Profunda.** Configuración de información sobre herramientas (Tooltips) personalizadas y obtención de detalles (Drill-through).
* **Día 15: Analítica Avanzada.** Uso de esquemas jerárquicos (Decomposition Tree) e influenciadores clave para desglosar métricas.
* **Día 16: Inteligencia Artificial Orientada a los Negocios.** Integración de narraciones inteligentes (Smart Narratives), preguntas y respuestas (Q&A) y detección de anomalías.

### Fase 4: Implementación y Mantenimiento (Servicio Power BI)
* **Día 17: Áreas de Trabajo (Workspaces).** Estrategias de publicación, roles de workspace y asignación de permisos.
* **Día 18: Puertas de Enlace (Gateways).** Configuración de actualizaciones programadas para mantener sincronizados los modelos con los servidores on-premise.
* **Día 19: Dashboards y Métricas Corporativas.** Creación de paneles gerenciales, suscripciones a reportes y configuración de Scorecards.
* **Día 20: Repaso General y Simulador PL-300.** Revisión de los dominios de la certificación y resolución de casos de estudio tipo examen.
